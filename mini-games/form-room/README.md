# Form Room

Twenty turn-paced games about textile interlacing, cumulative supports, constrained mechanical geometry and coupled materials. Each engine implements three finite studies, explicit failure, scoring and recovery through the shared Journey shell. All essential actions have native buttons; the canvas diagrams supplement exact public tables.

The mechanical models intentionally use bounded, clearly stated bench rules. They are game constitutive models, not engineering design tools. For example, Mesh Form assembles eight constant-strain plane-stress triangles, Fiber Panel solves its full six-component laminate matrix, and Resonator Rack solves a complex nodal admittance system. These actual coupled responses determine play; labels alone do not grant a win.

Ten games provide seeded challenge streams: Warp Shed, Corbel Tower, Fiber Panel, Remanence Bench, Sieve Cascade, Solvent Ladder, Emulsion Bench, Delaunay Bench, Thread Portrait and Rubber Boundary. Their bounded third-study dimensions remain capped at arbitrarily late stage numbers. The ten other games retain authored finite campaigns. A generated mode is withheld where geometric reachability, contact convergence or material access needs a more substantial certified generator.

`games.json` records precise rules, controls, actual source modules, nearest-game distinctions and optional-mode reasons. Public `?seed=INTEGER` replay uses the Journey stage-seed contract. Runtime contains no solution planner or browser state injection hook.

Run `BASE_URL=http://127.0.0.1:8790 node mini-games/tests/form-room.cjs`. The suite executes `form-room-regressions.mjs`, then genuinely activates every native control along all three finite studies, natural loss/recovery/restart paths and two generated challenges where supported. Desktop actions use focused native Enter/Space; mobile actions use Chromium emulated touchscreen taps. QA paths in `form-room-plans.mjs` are source/public-target-derived and are not evidence of unaided player difficulty. Generated property checks cover 100 seeds per supported game, including stages17 and128, separately from native browser scope.

`tests/form-room-opening.cjs` separately checks every opening smoke control through four public replay seeds on both keyboard and touch. Coverage reports bind all room files, shared Journey files and Form-prefixed test files; independent ordinary-player samples are owned by the release reviewers. Physical devices and assistive-technology user studies are outside the automated coverage.
