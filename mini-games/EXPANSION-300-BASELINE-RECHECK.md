## Material baseline changes

- Specimen Rule now selects 3–4 of eight labeled 2D prototypes so Manhattan nearest-neighbor labels classify all twelve references; conflicting equidistant labels are ambiguous. This is geometric model construction, no longer hidden-grammar experimentation.
- Question Orchard (`twenty-questions`) now constructs an entire depth-limited feature decision tree for all six records. No hidden individual exists. Building any other generic classifier is therefore not automatically unique.
- Transit Observatory selects a separating observation batch before seeing a report. Causal Lab repairs two failed edges between measurements. Lens Library identifies an ambiguous installed kernel and edits six integer source pixels. Archive requires dependency-closed compatible patches. These changes strengthen existing synthesis/inverse/repair territory.
- Safe Return locks collateral through differing durations; Convoy locks escorts through voyages with permanent casualties. Seed interleaves limited actions and nonlinear growth; Phase/Scissor/Quiet Foil now demand contingent choices. Clockmaker/Track add causal adventure and genuine staged cooperation.
